# BAND-AID 6 References

This folder stores source material that can support the BAND-AID 6 persona.

- `source/` contains original DCCS reference files using web-safe filenames.
- `references.json` is a manifest future RAG, search, citation, or reference-card features can use.

These files are staged first as a source library. Future work can add extracted text, slide thumbnails, citation links, or retrieval indexing without moving the source files again.
